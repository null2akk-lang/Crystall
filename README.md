# CRYSTAL DROP (версия для Cloudflare)

Русскоязычная игра для Telegram Mini Apps: кейсы со скинами CS2, апгрейды, инвентарь и приглашения. Новый гостевой профиль получает 1000 кристаллов, пригласивший — 5000. Кристаллы нельзя купить или вывести; интеграции со Steam нет.

## Как устроен проект

- `src/`, `index.html` — интерфейс (React + Vite), собирается в статические файлы в `dist/`.
- `worker/` — сервер на Cloudflare Workers: `/api/game` (игра) и `/api/admin` (панель разработчика).
- База данных — Cloudflare D1 (SQLite). Таблицы создаются автоматически при первом обращении к игре.
- `wrangler.jsonc` — настройки Cloudflare. Базу `crystal-drop` Wrangler создаёт сам при первой публикации.
- `tests/worker.test.ts` — проверки серверной логики (`npm run test:worker`).

Это та же игра, что была на Netlify, но с другой базой: **данные игроков с Netlify сюда не переносятся**, всё начинается с чистой базы.

## Публикация через GitHub (без командной строки)

1. Создайте репозиторий на github.com и загрузите в него **содержимое** этой папки (Add file → Upload files). Папку `node_modules` загружать не нужно, её здесь нет.
2. В панели Cloudflare откройте Workers & Pages → Create application → **Import a repository** (не «Upload your static files»), подключите GitHub и выберите репозиторий.
3. Укажите:
   - Project name: `crystal-drop` (должно совпадать с `name` в `wrangler.jsonc`);
   - Build command: `npm run build`;
   - Deploy command: `npx wrangler deploy`.
4. Нажмите Save and Deploy. Установка и сборка занимают несколько минут. База D1 создаётся автоматически.
5. Адрес сайта будет вида `https://crystal-drop.<ваш-поддомен>.workers.dev`. Его нужно указать в @BotFather (Configure Mini App / Menu Button).

Если сборка пишет ошибку про базу данных: создайте D1 вручную (Storage & databases → D1 → Create, имя `crystal-drop`), скопируйте её ID и добавьте в `wrangler.jsonc` в строку `d1_databases`: `"database_id": "<ID>"`.

## Публикация с компьютера

Нужен Node.js 22.13 или новее.

```
npm install
npx wrangler login
npm run deploy
```

## Локальная проверка

```
npm install
npm run test:worker     # серверная логика на локальной SQLite
npm run build && npm run dev:api   # сайт и API на http://localhost:8787
```

## Панель разработчика и промокод

Раздел «Промокоды» принимает скрытый промокод на 10 000 кристаллов (один раз на профиль). Его значение хранится только на сервере, в `worker/game.ts`, и игрокам нигде не показывается.

Там же есть поле кода доступа. Сейчас работает встроенный тестовый код из `worker/admin.ts`. Чтобы задать свой, откройте Cloudflare → ваш Worker → Settings → Variables and secrets и создайте секрет `CRYSTAL_ADMIN_CODE`. Он заменит встроенный код.

После входа (сессия 30 минут, лимит 5 попыток за 15 минут с одного IP) доступны:
- список игроков с поиском по ID и карточка игрока;
- выдача кристаллов и скинов (повтор запроса после сбоя не дублирует выдачу);
- блокировка на время или навсегда с причиной и разблокировка;
- журнал действий.

Заблокированный игрок видит экран блокировки и не может играть. Бан привязан к гостевому профилю и, если Telegram-аккаунт игрока подтверждён (см. ниже), ещё и к его Telegram ID: новый профиль того же аккаунта (очистили cookies, зашли с другого устройства) блокируется сразу, а разблокировка снимает бан со всех его профилей. Без подтверждённого Telegram ID бан действует только на один профиль (cookie).

## Ники и фото игроков из Telegram

Мини-приложение отправляет серверу `Telegram.WebApp.initData`; сервер сохраняет ник (`@username`), имя, Telegram ID и фото игрока. В панели разработчика вместо одних ID теперь видны аватарка и ник — в списке игроков, в карточке игрока и в журнале. Поиск работает по нику, имени, Telegram ID и началу внутреннего ID.

- Чтобы данные нельзя было подделать, добавьте секрет `TELEGRAM_BOT_TOKEN` (токен бота из @BotFather): Cloudflare → ваш Worker → Settings → Variables and secrets. Без него данные принимаются без проверки подписи — для отображения это допустимо, но ник может подделать только сам игрок у себя.
- **Бан по Telegram ID работает только с секретом `TELEGRAM_BOT_TOKEN`.** Без него ID нельзя доверять (его можно подставить), поэтому такие профили банятся только по cookie. В карточке игрока видно, привязан ли бан к Telegram-аккаунту.
- **Один профиль на один подтверждённый Telegram-аккаунт.** Несколько аккаунтов на одном устройстве больше не делят баланс и инвентарь, а тот же аккаунт на другом устройстве (или после очистки cookies) получает свой прежний профиль. Уже существующий профиль без Telegram достаётся первому аккаунту, который зайдёт после обновления; остальные начинают с новым профилем. Без `TELEGRAM_BOT_TOKEN` игра по-прежнему различает игроков только по cookie.
- Профиль игрока обновляется при каждом заходе в игру. Игроки, которые ещё не заходили после обновления, остаются с ID, пока не откроют приложение.
- Фото показывается, только если у игрока в Telegram оно есть и он разрешает его видеть; иначе — кружок с первой буквой ника.
- Игра должна открываться именно из Telegram (кнопка меню бота / Mini App). При открытии в обычном браузере ника нет.
- Существующая база обновляется сама: новые колонки добавляются при первом обращении.

## Заметки по базе D1

В D1 нет блокировок строк и интерактивных транзакций, поэтому изменения баланса и инвентаря проверяют номер версии профиля (`version`) и повторяются, если профиль успел измениться. Связанные записи (например, выдача и запись в журнал) выполняются одним пакетом (`batch`), который применяется целиком или не применяется вовсе.

## Апгрейд

На колесе шанса зелёный (при низком шансе — жёлтый или красный) сектор равен шансу успеха. После нажатия стрелка делает несколько оборотов и останавливается в секторе успеха или за его пределами в соответствии с реальным результатом, который сервер определил заранее. Цели можно фильтровать по шансу: «Надёжно» (40% и выше, максимум 75%), «Риск» (20–40%), «Критически» (0–20%). У каждой цели показан шанс.

## Изображения предметов

Картинки скинов хранятся в формате WebP (в 6 раз легче PNG), загружаются сразу при входе, а при сбое загрузки повторяются.

Изображения Valve лежат в `public/skins`, источник указан в `public/skins/ATTRIBUTION.md`. Предметы остаются виртуальными наградами этой игры; передача предметов Steam не предусмотрена, приложение не связано с Valve.
