# CRYSTAL DROP (версия для Cloudflare)

Русскоязычная игра для Telegram Mini Apps: кейсы со скинами CS2, апгрейды, инвентарь и приглашения. Новый гостевой профиль получает 1000 кристаллов, пригласивший — 5000. Кристаллы нельзя купить или вывести; интеграции со Steam нет.

## Как устроен проект

- `src/`, `index.html` — интерфейс (React + Vite), собирается в статические файлы в `dist/`.
- `worker/` — сервер на Cloudflare Workers: `/api/game` (игра) и `/api/admin` (панель разработчика).
- База данных — Cloudflare D1 (SQLite). Таблицы создаются автоматически при первом обращении к игре.
- `wrangler.jsonc` — настройки Cloudflare. Базу `crystal-drop` Wrangler создаёт сам при первой публикации.
- `tests/worker.test.ts` — проверки серверной логики (`npm run test:worker`).

Это та же игра, что была на Netlify, но с другой базой: **данные игроков с Netlify сюда не переносятся**, всё начинается с чистой базы.

## Публикация через GitHub (без командной строки)

1. Создайте репозиторий на github.com и загрузите в него **содержимое** этой папки (Add file → Upload files). Папку `node_modules` загружать не нужно, её здесь нет.
2. В панели Cloudflare откройте Workers & Pages → Create application → **Import a repository** (не «Upload your static files»), подключите GitHub и выберите репозиторий.
3. Укажите:
   - Project name: `crystal-drop` (должно совпадать с `name` в `wrangler.jsonc`);
   - Build command: `npm run build`;
   - Deploy command: `npx wrangler deploy`.
4. Нажмите Save and Deploy. Установка и сборка занимают несколько минут. База D1 создаётся автоматически.
5. Адрес сайта будет вида `https://crystal-drop.<ваш-поддомен>.workers.dev`. Его нужно указать в @BotFather (Configure Mini App / Menu Button).

Если сборка пишет ошибку про базу данных: создайте D1 вручную (Storage & databases → D1 → Create, имя `crystal-drop`), скопируйте её ID и добавьте в `wrangler.jsonc` в строку `d1_databases`: `"database_id": "<ID>"`.

## Публикация с компьютера

Нужен Node.js 22.13 или новее.

```
npm install
npx wrangler login
npm run deploy
```

## Локальная проверка

```
npm install
npm run test:worker     # серверная логика на локальной SQLite
npm run build && npm run dev:api   # сайт и API на http://localhost:8787
```

## Панель разработчика и промокод

Раздел «Промокоды» принимает скрытый промокод на 10 000 кристаллов (один раз на профиль). Его значение хранится только на сервере, в `worker/game.ts`, и игрокам нигде не показывается.

Там же есть поле кода доступа. Сейчас работает встроенный тестовый код из `worker/admin.ts`. Чтобы задать свой, откройте Cloudflare → ваш Worker → Settings → Variables and secrets и создайте секрет `CRYSTAL_ADMIN_CODE`. Он заменит встроенный код.

После входа (сессия 30 минут, лимит 5 попыток за 15 минут с одного IP) доступны:
- список игроков с поиском по ID и карточка игрока;
- выдача кристаллов и скинов (повтор запроса после сбоя не дублирует выдачу);
- блокировка на время или навсегда с причиной и разблокировка;
- журнал действий.

Заблокированный игрок видит экран блокировки и не может играть. Баны привязаны к гостевому профилю (cookie): после очистки cookies создаётся новый профиль.

## Заметки по базе D1

В D1 нет блокировок строк и интерактивных транзакций, поэтому изменения баланса и инвентаря проверяют номер версии профиля (`version`) и повторяются, если профиль успел измениться. Связанные записи (например, выдача и запись в журнал) выполняются одним пакетом (`batch`), который применяется целиком или не применяется вовсе.
